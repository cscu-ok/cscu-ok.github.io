# CSCU website

The public website for the Computer Science Course Union (CSCU) at UBC Okanagan — `https://cscusuo.org`.

**Status:** this is the `v2` rebuild in progress (Astro, replacing the old Cobalt site). The live site is still served from `main`; `v2` has not cut over yet. See `docs-site/DEPLOY.md` for the cutover plan.

## Quick start

```bash
npm install
npm run dev
```

See [`docs-site/CONTRIBUTING.md`](./docs-site/CONTRIBUTING.md) for full setup, branch workflow, and project structure. See [`docs-site/CONTENT.md`](./docs-site/CONTENT.md) to add content (events, team members, resources, posts) without running any tooling.
